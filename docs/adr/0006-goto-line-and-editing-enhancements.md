# 0006: 指定行號跳轉與編輯增強架構

為了使 MadEdit-Rust 在長文本與專業程式碼編輯場景下，能快速精確定位目標位置，並提供直覺高效的行級編輯操作，我們決定實作「指定行號與欄位跳轉（Go to Line & Column）」內嵌面板，以及一系列現代化程式碼編輯增強功能（行上下移動、行複製、行刪除、智慧行首）。

## Context

在編輯大型原始碼或檢視編譯錯誤、Log 日誌時，開發者常需要根據指定行號（如 `Ln 152, Col 18`）迅速跳轉到目標位置。
- 原生 Slint 限制：Slint 沒有內建的多功能輸入框或 Quick Open 彈窗，因此需透過自繪或條件內嵌面板實現。
- 操作流暢度：跳轉面板需支援標準快捷鍵 `Ctrl+G`，提供直覺的範圍提示（如 `行號 (1 - 1500):`），並支援語法如 `42` 或 `42:10`（指定行號與欄位）。在 Hex 模式下則切換至 Offset 位移跳轉。
- 現代編輯器必備功能：
  - 整行上下移動（`Alt+Up` / `Alt+Down`）：免去繁瑣的剪下貼上流程。
  - 整行複製（`Ctrl+Shift+D`）：快速拷貝當前行或選取區至下一行。
  - 整行刪除（`Ctrl+Shift+K`）：一鍵刪除當前行並自動維持游標合法性。
  - 智慧行首（`Home`）：首次按 Home 跳轉至第一個非空白字元（縮排後），再次按跳轉至第 0 欄。

## Decision

1. **內嵌式跳轉面板（Go to Line Panel）**：
   - 在 `ui/appwindow.slint` 中新增 `show-goto-panel` 屬性與對應面板元件，位於編輯區上方（與搜尋列風格一致）。
   - 提供行號範圍標籤、輸入框（`goto-input`）與「跳轉」、「取消」按鈕。
   - 快捷鍵支援：
     - `Ctrl+G`：展開跳轉面板，並將當前游標所在行預設填入輸入框，文字反白選取。
     - `Enter`：執行跳轉並關閉面板，編輯區重新獲得焦點。
     - `Esc`：關閉面板並返回編輯區。
   - 解析格式：支援 `Line` 或 `Line:Col`（例如 `100:15`），1-based 轉 0-based。超出邊界自動 Clamp 至合法範圍。
   - Hex 模式切換：在 Hex 模式下自動切換標籤為 `位移 Offset (0x0 - 0x...):`，支援十進位與十六進位（`0x...`）解析，直接定位 Hex offset 並捲動畫面。

2. **編輯器核心行編輯操作（Line Editing Operations）**：
   - 在 `EditorState`（`src/core/editor.rs`）與 `DocumentBuffer`（`src/core/buffer.rs`）中新增行級編輯 API：
     - `move_lines_up()` 與 `move_lines_down()`：支援單行或多行選取範圍整塊上移或下移，邊界安全檢查（首行不上移、末行不下移），維持游標與選取相對位置。
     - `duplicate_lines()`：無選取時複製游標所在整行並插入下一行；有選取時複製選取涵蓋的所有行並插入於下方。
     - `delete_lines()`：刪除游標所在整行（包含換行符），保留最後一行不致崩潰為空，游標自動調整。
     - `move_home_smart(expand_selection: bool)`：實作智慧行首導覽。
   - 所有行編輯操作皆自動觸發 `d.sync_from_editor()` 與 UI 即時重新渲染。

3. **鍵盤事件分派整合**：
   - 在 `src/main.rs` 的 `on_key_pressed` 分派器中：
     - 攔截 `Ctrl+G` 呼叫跳轉面板。
     - 攔截 `Alt+Up` / `Alt+Down` 呼叫整行上下移動。
     - 攔截 `Ctrl+Shift+D` 呼叫整行複製。
     - 攔截 `Ctrl+Shift+K` 呼叫整行刪除。
     - 強化 `Home` 鍵邏輯為智慧行首。

## Consequences

- 大幅增強 MadEdit-Rust 面向專業程式設計師與程式碼閱讀的工作流體驗。
- 行移動與行刪除在內部 `Vec<String>` 行快取中操作簡單直接（KISS 原則），時間複雜度極低且邏輯嚴謹。
- 與現有的自繪編輯器元件、列塊模式與語法突顯完全相容且無衝突。
